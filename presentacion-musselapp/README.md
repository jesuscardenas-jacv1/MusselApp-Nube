# Presentación de la aplicación MusselApp

Presentación de **MusselApp v1.3.2** para la evaluación del ramo (DSY1105, Duoc UC).

## Cómo abrirla

Descarga `MusselApp-Presentacion.html` y ábrela con doble clic en Chrome o Edge. Es un solo archivo: trae imágenes, fuentes y animaciones adentro y no necesita internet.

| Acción | Tecla |
|---|---|
| Avanzar | `→`, `Espacio` o clic en el borde derecho |
| Retroceder | `←` o clic en el borde izquierdo |
| Pantalla completa | `F` |

## Contenido

1. **La nueva MusselApp:** flujo operativo en nueve etapas.
2. **Recorrido por la app:** cada pantalla antes (v1.0) y ahora (v1.3.2), con animaciones de las funciones nuevas.
3. **Lo que hay detrás:** Firebase, APIs externas, Retrofit, backend Spring Boot + Swagger y la guía de pruebas en vivo.
4. **Cierre:** cifras del proyecto y conclusiones.

La diapositiva **Pruebas en vivo** tiene los comandos y los JSON listos para copiar. Su botón **Abrir** apunta a `http://localhost:8080/swagger-ui.html`, así que solo funciona en el computador donde esté corriendo el backend.

En **Portal web de supervisión** cada avance trae una página del portal al frente; también se puede hacer clic en el menú. **Usarlo aquí, en vivo** carga el portal publicado con datos de ejemplo (necesita internet): mientras está abierto las flechas no avanzan, hay que presionar **Volver a las pantallas**.
